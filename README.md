# Процедурный кабинет (простая версия)

Система записи пациентов в процедурные кабинеты клиники (уколы, системы). Запись оформляет оператор по телефону; пациенты не регистрируются.

## Возможности
- Календарь на выбранную дату: свободные и занятые слоты по кабинетам и специалистам
- Настраиваемая длительность процедур, запрет двойной записи на один интервал
- Перенос и отмена записи, история сохраняется
- Очередь со статусами: Ожидает, Вызван, На процедуре, Завершено, Отменено, Не явился
- Вкладка «Настройки»: кабинеты, специалисты, процедуры
- Русский и казахский языки

## Хранение данных
Версия без сервера: все данные хранятся в `localStorage` браузера на одном
компьютере. Следствия:
- работает на одном рабочем месте; другие устройства и операторы этих записей не увидят;
- очистка данных браузера удалит все записи;
- вкладка «Настройки» доступна всем, кто открыл страницу, паролей нет.

Для нескольких операторов нужен общий backend и база данных.

## Запуск
Откройте `index.html` в браузере или разместите на GitHub Pages
(Settings → Pages → Deploy from a branch → main / root).
